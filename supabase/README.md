# TableTime database

The initial migration defines organizations, memberships, locations, employees, shifts, time entries, breaks, staff requests, and immutable audit events.

Security rules:

- All public tables have Row Level Security enabled.
- Employees can only read data belonging to an organization they belong to.
- Manager and owner writes are checked against database membership records.
- Client-editable user metadata is never used for authorization.
- The mobile client receives only a publishable key.
- Clock timestamps are generated by narrow authenticated database functions.
- Partial uniqueness prevents an employee from having two open time entries.
- Composite foreign keys prevent cross-organization employee/location references.

Run locally after Docker Desktop is healthy:

```bash
npx supabase start
npx supabase db reset
npx supabase db lint --local
```

Do not apply this migration to an existing project until confirming that project is dedicated to TableTime.
